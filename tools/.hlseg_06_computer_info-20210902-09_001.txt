001、透亮肌膚是指畫面能感到皮下血色與光線散射，而不是表面塗死一層不透明色塊。
002、判斷透亮看明暗交界帶：該帶若同時有色相偏移與微弱血色，比只把明度壓暗更接近真皮效果。
003、肌膚不是單一固有色，而是底色、血色、陰影色、高光色與環境色疊加後的光學結果。
004、底色要選能同時往亮與往暗推的中間明度，過亮沒有陰影空間，過暗會讓血色與高光失去層次。
005、底色飽和度宜偏低暖黃或低彩橘粉，過高飽和會讓後續 Multiply 與 Overlay 立刻變成塑膠感。
006、陰影禁止只用底色加黑，黑會抽走色相使交界變髒灰，應改用帶藍紫、橄欖或紅褐的暗色。
007、主光偏暖時陰影可略偏冷，主光偏冷時陰影可略偏暖，用色溫對比建立體積而不是只用明度差。
008、血色層模擬真皮微血管透出，不是口紅式塗紅，應落在薄皮與充血處並保持半透明。
009、薄皮好發於耳廓、鼻頭、指節、指尖、肘、膝、眼瞼、唇周與關節內側，這些區域優先加血色。
010、厚皮或骨點如額頭中央、鼻梁、下巴尖，血色要少，改讓高光與固有色主導。
011、Multiply 用來壓暗並讓底下色相仍可見，適合形體陰影與接觸陰影，不拿來做高光。
012、Overlay 對比較強、Soft Light 較不易炸掉飽和度，兩者都用來推血色與中間調冷暖，而不是整層改固有色。
013、Add Glow、Linear Dodge（Add）與 Color Dodge 只負責高光與透光，用量過大會過曝並吃掉膚色。
014、Screen 適合柔光型亮部與環境反射，比 Add 系更不容易把皮膚燒成白塊。
015、圖層由下而上建議為底色色塊、形體陰影、接觸陰影、血色、環境色、高光、質感，方便單獨改色溫。
016、陰影、血色、高光必須分層可逆，不要在同一層用橡皮擦硬改到無法再調色相。
017、筆刷硬度依邊緣功能切換：形體轉折與軟骨輪廓用偏硬邊，圓渾面與面頰用偏軟邊。
018、低不透明度多次疊加才能保留底下血色與底色，一次塗滿會把透亮所需的下層資訊蓋死。
019、混色過度會把交界帶抹成同一灰橘，應在混勻後補回冷暖差，否則色相層次會消失。
020、混色不足會留下色塊接縫；合格交界應有寬窄變化，而不是均勻一條帶。
021、terminator（明暗交界帶）應略提高飽和並可帶紅橘，避免從受光直接跳到死黑。
022、接觸陰影比形體陰影更暗、更窄、更貼縫，例如頸下、鼻翼旁、手指夾縫，不可整面同樣深。
023、形體陰影隨體面轉向緩緩變暗、邊緣較軟；接觸陰影幾乎貼著接觸線、邊緣較硬。
024、漫射高光是體面受光變亮且仍帶膚色；鏡面高光是油分光點，接近光源色且面積小。
025、油性或青春感加強小面積鏡面高光；乾燥或粉霧感減少鏡面、拉長漫射亮部。
026、高光色不要純白：日光帶淡黃、窗光帶青白、黃昏帶橘，純白會讓皮膚像陶瓷釉。
027、眼下、鼻翼溝、口輪附近若只加陰影不加血色容易像瘀青，應在暗部邊緣補低彩紅。
028、環境色來自周圍反射：近綠衣的下顎與頸側可吃一點綠，近暖牆則吃橘，不是額外亂加彩。
029、環境色落在半影與背光側的受反光面，不要蓋過主受光面的固有膚色。
030、背光時耳、鼻翼、指縫等薄組織應比臉頰更亮更紅橘，這條透光帶是透亮的強證據。
031、透光帶用 Overlay 或 Add 的低彩紅橘沿著薄緣走，不要整塊臉加同一發光。
032、硬光陰影邊緣清楚、高光更銳；軟光陰影邊緣糊、血色更勻，兩者的透亮手段不同。
033、硬光靠交界帶色相與薄組織透光做出透亮；軟光靠整體血色分佈與微弱冷暖，而不是強高光。
034、室內窗光常是一側冷一側暖：受光可偏青白，背光與室內反射可偏橘褐，用來分開空間。
035、黃昏光把受光面染暖時，陰影仍需保留相對偏冷或偏洋紅的暗部，否則會變成單色濾鏡。
036、燈光色溫改變的是高光與受光面色相，底色不必整層換成光源色，保留膚色再疊光源層更可控。
037、白皙膚底色偏低彩粉黃，陰影容易偏青紫，血色相對明顯，高光要克制以免粉掉。
038、小麥膚底色偏暖褐橘，陰影可偏紅褐或橄欖，血色與底色距離較近，要靠飽和差而不是狂加紅。
039、深色膚的透亮不靠塗粉紅，而靠高光的光源色、交界帶的高飽和暖色，以及極克制的紅褐血色。
040、深色膚應從較深暖底開始，亮部用 Overlay 或 Add 點出；若用淺膚高明度底再 Multiply，會變成灰蒙。
041、膚色是否成立看受光、中間調、陰影三帶的色相能否分開，而不是只有明度三階。
042、過黑過粗的輪廓會把皮膚切成貼紙，著色階段應降低線濃度或讓線吃進膚色。
043、外輪廓可略清晰以成立剪影；鼻唇溝、眼袋等內輪廓必須軟、窄並帶血色。
044、外輪廓迎光側可溶進背景或加窄 rim，背光側較實，避免整圈同等硬度。
045、Rim light 是輪廓受環境或逆光的窄亮邊，色相跟光源走，寬度隨形體厚度變，耳垂與肩可比臉頰寬。
046、流量低適合掃血色漸層，不透明度低適合疊高光，兩者同時拉滿容易一次蓋死下層。
047、噴槍負責大面積光影與血色過渡，硬邊筆刷負責骨點、皺褶轉折與高光形狀，質感筆刷只在最後極薄加。
048、先把體積、血色、高光成立再開質感；過早加毛孔雜點會破壞色層閱讀。
049、質感只加在受光的中間調，陰影裡應被光影吃掉，均勻鋪滿會像印花布。
050、先決定光源色、陰影色、血色三個樞紐色，再讓底色當它們的中間橋，而不是先吸一個膚色就塗全身。
051、吸色要吸過渡帶，不要吸最亮或最暗，才能維持連續的色相路徑。
052、若走灰階再上色，上色階段必須用 Overlay 或 Color 層把交界帶與薄皮重新加暖，否則會失去皮下散射。
053、直接彩色塗的優勢是一開始就建立色溫，但要定期去飽和檢查形體是否仍清楚，避免被顏色騙過體積。
054、飽和度在交界帶與薄皮可以提高，在大面積中間調和深陰影核心應降下來，否則整臉像發燒。
055、陰影核心最暗處仍應看得出色相；若已接近無彩黑，往交界帶回退半級並加暖或加冷。
056、亮部若只提高明度卻降低飽和會粉化；合格亮部應略帶光源色相，並在旁邊保留中飽和膚色。
057、粉化的判斷是亮部明度升高同時彩度崩成灰白；合格亮部仍帶光源色，並緊貼一塊中飽和膚色。
058、髒灰的判斷是陰影接近無彩色且交界沒有冷暖；合格陰影即使很暗仍能讀出藍紫、橄欖或紅褐。
059、塑膠感的判斷是高光形狀均一、血色缺失、terminator 只有明度差；合格皮膚的高光有形，半影有半透明紅橘。
060、蠟像感的判斷是整臉平滑度與粉橘量過於平均；合格皮膚在骨點較硬，面頰與額頭血色量不同。
061、同一張臉的額頭、面頰、下顎不該同一底色走到底：額頭偏黃、面頰偏血色、下顎可略偏冷綠灰。
062、身體膚色比臉常略低飽和或略深，手肘膝蓋又比小臂更偏紅褐，用部位差避免臉與身體像不同材質。
063、指腹與關節背側多血色，骨感與指甲周圍少血色、多高光，三區分開才不會把手畫成香腸。
064、唇周皮膚薄且常偏紅，但要和唇色分層，避免把嘴唇色直接糊到人中造成汙漬感。
065、眼瞼受光可偏紅紫，眼窩是接觸陰影，兩者相鄰時用軟邊過渡，不要畫成兩塊色票。
066、圖層模式的強度用不透明度微調：先選對模式，再把 opacity 收到看得到但還能還原底色。
067、Multiply 層的填色應比直覺更淺更有彩，因為相乘後會再變暗；一開始就塗很深會在交界失去透亮。
068、Overlay 對中間灰附近影響較小，偏亮暖色會提亮並加彩，偏暗冷色會壓暗，適合做局部冷暖。
069、Add Glow 只用遮罩限制在真正吃到光源或透光的像素，避免整層發光把對比洗掉。
070、剪貼遮罩讓陰影與血色不溢出底色色塊，是維持邊緣乾淨又不怕大膽疊色的基本結構。
071、只有當該層功能已定、不再需要單獨改色溫時才合併；血色與高光盡量留到最後。
072、縮小檢查三大面與體積是否成立，放大只檢查交界帶色相、薄皮透光與高光形狀。
073、關掉血色層應立刻變蠟、關掉高光層應變平但不變死、關掉陰影層應失去體積，代表三層分工正確。
074、預設一個主光加一個弱反光，第三個光只當 rim 或眼神光；多主光會讓交界帶互相取消，透亮無從依附。
075、工具服從光學任務：要透就用半透明疊色與暖交界，要體積就用清楚的 terminator 與 occlusion，不要用同一支軟噴槍解決所有問題。
