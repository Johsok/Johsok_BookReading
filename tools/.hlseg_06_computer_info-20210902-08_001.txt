001、數位影像是高×寬的像素陣列，灰階一格一個強度、彩色一格三個通道值，機器學習能算的前提是先把圖變成數值張量而不是檔案路徑。
002、OpenCV 的 imread 預設通道順序是 BGR，多數深度學習預訓練權重假設 RGB，沒做 cvtColor 就餵模會讓紅藍特徵對調、顏色相關類別會系統性誤判。
003、灰階化用加權亮度壓成單通道，適合閾值、邊緣、輪廓這類不靠色相的算子；若類別差在顏色（成熟度、指示燈），灰階會把可分線索丟掉。
004、HSV 把色相、飽和度、明度拆開，inRange 抓色塊時應寬鬆 H、適度限制 S、讓 V 隨光照浮動，直接在 BGR 立方體切門檻會隨曝光漂移。
005、空間取樣決定能不能解析細紋與小缺陷，強度量化決定層次是否被併階；目標小於數個像素時，再深的分類器也只能學到糊塊而非形狀。
006、ROI 先裁任務相關矩形再運算，可降背景干擾與計算量；框必須含完整目標與穩定邊距，裁到半個物件會讓輪廓特徵與卷積感受野都失效。
007、NumPy 影像 shape 是 (列, 行) 即 (高, 寬)，可選最後一維通道，索引 [y, x] 與口語「寬×高」相反，寫反會得到轉置圖或靜默錯位特徵。
008、uint8 範圍是 0–255，濾波與加權混合若在 uint8 直接加減會模 256 繞回，亮邊變黑斑；應先轉 float 運算再 clip 回合法範圍。
009、像素除以 255 縮到 0–1，或減資料集／ImageNet 均值再除標準差，能讓梯度尺度穩定；訓練做了標準化、推論沒做，等於換了一套輸入分布。
010、線性平滑是核與鄰域加權和，GaussianBlur 的 sigma 控制空間截止頻率，sigma 過大連真邊緣一起沒，應小到雜訊降、輪廓梯度仍可被 Canny 接到。
011、中值濾波取鄰域中位數，椒鹽極值進不了中位數所以去噪強；核大於細線寬時會把文字筆畫或刮痕當噪點吃掉，核尺寸要小於最小需保留結構。
012、雙邊濾波同時看空間距離與亮度差，平坦區去噪、跨邊少混色，比高斯慢一個數量級，鏡頭即時管線要先量 fps 再決定能否取代 GaussianBlur。
013、卷積核權重和為 1 且全正近乎低通平滑；中心正、周圍負近乎高通銳化或邊緣；同一核旋轉 90 度可分別強調垂直或水平結構。
014、Sobel 用分離核近似 x、y 一階導數，梯度幅值大處是邊緣、方向角可供 HOG；只取單一方向會漏掉與該軸平行的邊界。
015、Laplacian 是二階導數，對細邊緣敏感也對高頻噪敏感，實務應先高斯再 Laplacian，否則二值化後會出現滿版碎點偽輪廓。
016、Canny 經平滑、梯度、非極大值抑制與雙閾值滯後連接，高閾決定可靠強邊、低閾決定可被連上的弱邊，兩閾比例不當會斷線或把紋理全當邊。
017、全域 THRESH_BINARY 假設前景背景強度可一刀切；光照不均、陰影落在工件上時應改 adaptiveThreshold，用局部均值或高斯當門檻而非單一常數。
018、Otsu 最大化兩類灰階的類間方差來自動選閾，資料需大致雙峰；多峰、漸層玻璃或反光帶會把閾值推到錯誤谷底，不能當萬能自動分割。
019、侵蝕縮小亮前景、清孤立白噪；膨脹擴大前景、填小黑洞；開運算先侵蝕後膨脹去突刺，閉運算相反補縫，順序反了會得到相反的幾何結果。
020、形態學核的形狀與邊長是尺度選擇：核大於最小真缺陷會把缺陷當噪消去，核太小則去不掉真噪；圓核較不傷轉角、矩形核較傷斜邊。
021、findContours 只能在二值圖追連通外邊界，後續可用面積、周長、boundingRect、minAreaRect 當幾何特徵；前景碎裂時一物會變多輪廓，面積門檻要跟著調。
022、輪廓檢索模式決定是否保留孔洞階層，數孔、環狀墊片、字體封閉區要用能回傳父子關係的模式，只取最外層會把內孔當成不存在。
023、影像矩可推重心與方向，Hu 矩對平移、尺度、旋轉相對不敏感，適合作傳統分類器的形狀向量；嚴重遮擋或非剛體變形時矩會漂到另一類。
024、直方圖只描述強度出現頻率、不含空間配置，equalizeHist 拉全域對比也放大噪；CLAHE 分塊並限制對比增幅，背光或低對比片比全域均衡化穩。
025、matchTemplate 以滑窗算與模板的相關或差異，正規化相關係數對整體亮度偏移較穩，但旋轉、尺度、透視一變峰值就塌，只適用姿態幾乎固定的小偏移。
026、Hough 直線把邊緣點投到 ρ–θ 累積，適合標線、管件、文件邊；θ 量化太粗會併兩條近平行線，投票閾太低會在紋理區冒出假直線。
027、仿射用 2×3 矩陣做平移、旋轉、等比或非等比例縮放與剪切，warpAffine 若不重算畫布尺寸，旋轉後四角會被裁掉導致特徵缺失。
028、透視用四組對應點估 3×3 單應再 warpPerspective，可把斜拍平面校成正視；對應點點錯會切變扭曲，且模型假設目標近似平面。
029、縮小解析度優先 INTER_AREA 以降低混疊，放大用 INTER_LINEAR 或 INTER_CUBIC；INTER_NEAREST 快但呈塊狀，會把 CNN 低層邊緣濾波器餵成鋸齒偽特徵。
030、資料增強只允許不改標籤語意的變換：小角度旋轉、亮度對比、輕微裁切通常安全；左右翻轉會改有方向性的號誌或文字類別，必須按任務關閉。
031、特徵是把像素壓成較低維、類間可分的描述：傳統路徑手動設計 HOG、LBP、顏色直方圖；CNN 則讓卷積核在損失驅動下自己學濾波器。
032、HOG 在 cell 統計梯度方向並於 block 內正規化，對行人、直立剛體有辨識力，對大變形、重遮擋或極低對比會失效，視窗大小必須對齊目標尺度。
033、LBP 把中心與鄰域灰階比較編成二進位碼，描述局部紋理且對單調光照變化相對穩，適合材質、織物、皮膚差異，不適合純靠幾何輪廓的任務。
034、監督式影像學習需要成對的樣本與標籤，標籤可以是類別、框或像素圖；標註錯誤會被當成真理寫進權重，驗證集若含同樣錯誤會讓指標虛高。
035、K-Means 依特徵距離把像素或色塊分成 K 群，可做粗分割或主色量化；K 大於真實層次數會切碎同一物件，K 太小會把不同物併成一群。
036、訓練、驗證、測試應以影像張、拍攝場次或機台為單位切分，禁止同一張圖的裁塊同時進訓練與測試，否則準確率衡量的是記憶而非泛化。
037、過擬合是訓練損失持續降、驗證損失回升，模型在背樣本；欠擬合是兩邊都高，容量或特徵不夠。早停、權重衰減、dropout、增強用來壓過擬合。
038、KNN 以特徵空間最近 k 票決定類別，k 太小噪、太大邊界糊；原始像素維度高且慢，實務應先縮圖、抽 HOG 或 PCA 再送入。
039、SVM 最大化類間間隔，線性核適合已可分特徵，RBF 核可處理彎曲邊界但要調 C 與 gamma；HOG 加 SVM 是經典二分類骨架，多類需一對多或一對一。
040、隨機森林對混合數值特徵較不需嚴格標準化，可吃輪廓幾何加顏色統計；直接把高維展平像素當輸入會不穩且難解釋，不是影像端到端首選。
041、減均值除標準差讓 SVM、KNN、神經網路各維尺度可比，否則大動態範圍通道會主導距離與梯度；樹模型對單調縮放不敏感，可省略但並非必須省略。
042、PCA 保留共變異最大方向以降維，可壓 HOG 或展平像素加速 KNN／SVM；若類間差落在小變異分量上，截斷後可分性會明顯下降，要以驗證準確率決定維數。
043、K-fold 估泛化時，影像若來自同一批次、同一病人或同一機台，隨機切會洩漏相關樣本，應改 GroupKFold 或依時間、產線批次切。
044、多層感知器以加權和加非線性堆疊逼近決策面，隱藏層太淺學不到層次組合，太深在小影像集上參數多於樣本，優先出現過擬合而非精度提升。
045、CNN 用同一組卷積核掃整張圖，權重共享使特徵具平移偵測能力，比全連接直接吃所有像素參數少，並保留局部空間結構給後層組合成物件。
046、卷積層輸出通道數等於該層濾波器數，3×3 核堆疊可在較少參數下擴大感受野，1×1 核用來混通道與降維，stride 大於 1 會同步降空間解析度。
047、ReLU 將負激活歸零以減輕梯度消失並造成稀疏；若學習率過大導致大量神經元長期為零，稱 dying ReLU，可改 Leaky ReLU 或降學習率觀察驗證損失。
048、MaxPooling 取局部最大激活，降尺寸並對小平移較不敏感；stride 與視窗過大時，小於該尺度的瑕疵在特徵圖上會消失，小物件任務應保留較高解析度特徵圖。
049、分類頭若先把特徵圖展平再接 Dense，參數量隨高×寬×通道暴增；改 Global Average Pooling 再接類別數節點，可減過擬合並讓通道對應類別熱區較可解釋。
050、Softmax 將 logits 轉成加總為 1 的互斥類別機率，配分類交叉熵；任務若允許重疊標籤（多病徵同時存在）應改獨立 sigmoid，硬套 Softmax 會互斥掉真組合。
051、反向傳播沿計算圖把損失對權重的梯度傳回，學習率過大會震盪或 NaN，過小則平坦區爬不動；Adam 對初始學習率較寬容，但仍要以驗證曲線而非訓練準確率調。
052、批次大小決定梯度估計雜訊與顯存占用，過小更新吵、過大有時損害泛化且裝不下高解析圖；改批次時常需按比例調整學習率並重看驗證集，不能只搬舊超參數。
053、遷移學習載入在大型自然影像集訓過的卷積基座，凍結低層泛用邊緣與紋理、只訓頭或微調高層，幾百到幾千張任務圖時通常比隨機初始化深網更穩。
054、預訓練網有固定輸入邊長，強制拉伸會改變長寬比、把圓當橢圓；應等比縮放後 letterbox 補邊，並在推論用同一套補邊規則，否則框座標還原會偏。
055、推論必須關閉 dropout 的隨機遮罩，BatchNorm 改用訓練期移動平均的均值方差；若仍開訓練模式，同一張圖多次前向會得到不同分數，無法當穩定門檻。
056、影像分類對整張輸出一個標籤，隱含「圖中主體單一且背景無競爭物」；多物件、要位置或要計數時，分類分數無法指向哪個區域，應改偵測或分割。
057、滑窗偵測以多尺度視窗加分類器掃圖，步長小較不易漏、計算量近似與窗數成正比；古典 HOG+SVM 行人偵測能用，但在高解析多類上很难同時滿足漏檢與即時。
058、Two-stage 偵測先區域提案再分類回歸，通常較準、延遲較高；One-stage 如 YOLO、SSD 在網格直接出框與類別，較適合嵌入式鏡頭，小物件與極端長寬比要另補策略。
059、錨框是預設寬高先驗，與真實框的 IoU 用來分配正負樣本；錨統計若與資料長寬比差太遠，極細刮痕或接近正方形的臉會收斂慢，應依資料集聚類錨而非沿用別任務錨。
060、IoU 為預測框與真實框交集除聯集，既是正確門檻也是 NMS 依據；NMS 的 IoU 閾過低會刪掉緊鄰真物，過高會留下同一物的重複框，要依目標最小間距設定。
061、偵測品質用各類 AP 再平均成 mAP，並應報告特定 IoU（如 0.5）與較嚴 IoU 的結果；只報整張圖 classification accuracy 會掩蓋定位差但類別碰巧對的模型。
062、語意分割給每個像素一個類別，實例分割還要拆開同類不同個體；需要面積、邊界或重疊器官／零件時必須像素級輸出，分類或粗框無法支撐量測。
063、混淆矩陣顯示每類被判成哪類，可定位「常互咬」的類對以決定要不要加特徵或合類；整體 accuracy 在良品佔九成以上時，全判良品也會看起來很高。
064、精確率是預測為正之中真為正的比例，召回率是真為正之中被找出的比例；漏檢代價高就提高召回（接受較多誤報），誤報會停機就提高精確率，閾值不能只取 0.5。
065、F1 是精確率與召回率的調和平均，適合兩種錯誤代價接近時排模型；正樣本極稀時應看 PR 曲線下面積，ROC-AUC 在大量真負下容易偏樂觀。
066、OpenCV 處理讀寫、相機、幾何與經典影像算子，NumPy 負責切片、廣播與向量化，兩者 dtype 與連續記憶體布局不一致時，後續卷積或 sklearn 會得到錯 shape 或複本開銷。
067、scikit-learn 吃二維特徵表做 SVM、KNN、隨機森林與交叉驗證，不負責 GPU 上的大 CNN；端到端影像深度模型應接到 Keras／TensorFlow 或 PyTorch，再把向量特徵可選回 sklearn。
068、Keras Sequential 只適合單輸入直線堆疊的分類 CNN；多輸入融合影像與表格、殘差捷徑或 U-Net 編碼解碼跳接必須用 Functional API，硬塞 Sequential 會接不出對稱結構。
069、同時畫訓練與驗證損失才能診斷：雙降表示在學、訓練降驗證升是過擬合、雙橫盤是學習率、標籤或資料管線有問題，不能只看最後一個 epoch 的 accuracy。
070、類別極度不均時應提高少數類 class weight、對缺陷圖 oversample，或改 focal loss 降低易分良品的權重，否則交叉熵最小值會落在「全判多數類」。
071、訓練與推論必須共用同一條前處理：色彩空間、縮放插值、裁切規則、均值方差；只在訓練做 CLAHE 或只在推論做模糊，等於讓模型在偏移分布上做決定。
072、相機曝光、白平衡、焦距、壓縮率若與訓練取像不一致，邊緣強度與色相統計會位移，固定閾值與未微調的 CNN 分數都會漂，部署前要用實機樣本重估門檻或做域適配。
073、背景單純、光源可控、目標可用閾值與輪廓描述時，OpenCV 經典鏈可解釋、省標註；外觀多變、紋理細微、難寫規則時改 CNN 或遷移學習，兩者可用經典法做提案、CNN 做辨識而串接。
074、樣本只有數百張時不宜從零訓練很深的 ResNet，應優先小網加遷移學習，或 HOG／幾何特徵加 SVM；驗證指標停滯再加寬深度，容量大於資料只會背下訓練圖。
075、可重現實驗需固定隨機種子、記錄 OpenCV／框架版本、輸入尺寸、增強參數與決策閾值，版本差異會改變 JPEG 解碼、resize 實作與非極大值抑制細節，導致同一權重得到不同框與分數。
